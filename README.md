# 🚀 IdeaVault – Startup Idea Sharing Platform

🌐 **Live Website:** https://idea-vault-omega.vercel.app/

IdeaVault is a modern startup idea-sharing platform where users can publish innovative startup ideas, explore ideas shared by others, and engage through comments and discussions. The platform encourages creativity, collaboration, and community-driven idea validation.

---

# ✨ Features

- 🔐 Secure authentication using Email/Password and Google Sign-In.
- 🛡️ JWT-based authentication to protect private routes.
- 💡 Create, update, and delete your own startup ideas.
- 🔍 Search ideas by title and filter ideas by category.
- 💬 Add, edit, and delete your own comments on ideas.
- 📈 Trending Ideas section to discover popular startup ideas.
- 👤 Update and manage your user profile.
- 🌙 Dark & Light theme support.
- 📱 Fully responsive design for Mobile, Tablet, and Desktop.
- ⚡ Modern UI with toast notifications for all CRUD operations.

# 🚀 Installation

### Clone the repositories

```bash
git clone https://github.com/rakib97j/Idea-Vault.git
git clone https://github.com/rakib97j/Ideavault-server.git
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
